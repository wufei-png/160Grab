# 160Grab 项目简介

160Grab 是健康160医生页预约辅助工具，提供 Python/Playwright 和 Tampermonkey 两种使用方式。用户手动登录、处理验证码并核对预约信息，程序按条件查询号源并准备预约表单。

- Python 使用独立浏览器 profile；Tampermonkey 在用户的浏览器页面中运行。两条路径的授权和提交记录各自保存，不应同时运行。
- `manual_confirm` 准备后交给用户；`auto` 还需要针对目标和就诊人明确授权，最终最多执行一次提交动作。
- 站点协议、验证码、支付和未知结果需要人工处理。提交后如无法核实结果，应到健康160查看预约记录，不要重复提交。
- 不伪造就诊人、诊疗卡、病情或地址；已有值冲突或缺少必填信息时停止并交人工处理。
- 常规日志使用脱敏的固定字段。原始页面调试快照需要显式开启敏感调试和私有目录，处理方式见[安全与隐私](../security-and-privacy.md)。

使用方法、配置与当前限制见 [README](../../README.md)；现场验证范围见 [本机 canary 记录](../live-canary.md)。
